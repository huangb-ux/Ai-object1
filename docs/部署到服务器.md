# 部署到自己的云服务器

Vercel 版已经在线（`https://zhangdeng.vercel.app`），这份文档是「换一台自己的服务器」的版本。
适用场景：想要国内直连、想练 Docker/Linux、或者面试时要现场演示。

## 1. 选一台机器

| 方案 | 价格 | 说明 |
| --- | --- | --- |
| **Oracle Cloud Always Free** | 永久免费 | 4 核 ARM / 24GB 内存 / 200GB 盘，最香；注册需要一张能扣 1 美元的信用卡或借记卡做验证（招行/中行 Visa 借记卡通常可以） |
| **腾讯云 / 阿里云 轻量应用服务器** | 新用户试用 1～3 个月免费，之后约 ¥24/月起 | 需要实名认证；国内节点，延迟最低；到期可换学生机 |
| **Serv00 免费空间** | 永久免费 | 共享空间、没有 root，跑 Next.js 这种常驻 Node 服务比较吃力，不推荐 |

配置要求：**1 核 2G 起**（构建阶段比较吃内存，1G 的机器请先加 1～2G swap）。

## 2. 需要准备的三个信息

部署时需要你把这三样给我（或者你自己照着做）：

1. 服务器 **公网 IP**
2. **SSH 用户名**（Ubuntu 默认 `ubuntu`，Debian/CentOS 默认 `root`）
3. **密码**，或者你把公钥加到服务器上、我来用密钥登录

系统建议选 **Ubuntu 22.04 / 24.04**，其余系统也能跑，只是装 Docker 的命令略有差别。

## 3. 一键部署

连上服务器后：

```bash
# 1) 拉代码（国内服务器如果拉不动 GitHub，用下面的镜像地址）
git clone https://github.com/huangb-ux/Ai-object1.git zhangdeng
cd zhangdeng

# 2) 部署（没有域名就用 IP 直接访问）
bash scripts/deploy.sh

# 或者：用它自带的一键 HTTPS（sslip.io 免费解析，<ip>.sslip.io 会解析到这台机器）
DOMAIN=$(curl -s https://api.ipify.org).sslip.io bash scripts/deploy.sh
```

脚本会自动：装 Docker → 建 `data/` 目录 → `docker compose up -d --build` → 起 Caddy 反代。

完成后：

- 没域名：`http://<服务器IP>`
- 用了 sslip.io：`https://<服务器IP>.sslip.io`（证书自动签发）

## 4. 关于 HTTPS

`sslip.io` 是一个免费的通配 DNS：`1.2.3.4.sslip.io` 永远解析到 `1.2.3.4`。
Caddy 会为它自动申请 Let's Encrypt 证书，**不需要买域名**。
等以后有了自己的域名，把 A 记录指向服务器 IP，再执行：

```bash
DOMAIN=你的域名 docker compose up -d
```

Caddy 会自动换成新证书。

## 5. 日常运维

```bash
docker compose logs -f app    # 看应用日志
docker compose restart app    # 重启
git pull && docker compose up -d --build   # 更新代码
docker compose down           # 停止
```

数据落在宿主机 `./data/zhangdeng.db`（SQLite），备份直接拷这个文件。

## 6. 想接大模型

编辑服务器上的 `.env`：

```bash
LLM_API_KEY=sk-xxxx
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

然后 `docker compose up -d`。不填也能用，走本地规则引擎。

## 7. 常见问题

- **构建时 OOM 被杀**：机器内存太小，先加 swap：
  `fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile`
- **拉 GitHub 慢**：把仓库地址换成镜像站，或者先用本机 `git bundle` 打包再上传。
- **80/443 打不开**：云厂商控制台的「安全组」要放行 80、443（脚本只改了系统防火墙 ufw）。
- **证书申请失败**：确认域名已经解析到这台机器、且 80 端口从公网可达（Let's Encrypt 要走 HTTP-01 验证）。
