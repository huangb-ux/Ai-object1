# 掌灯 · 面试讲解

这份文档是给你自己看的：怎么在三分钟里把这个项目讲清楚，以及被追问时怎么答。

## 一句话版本

> 我做了一个智能家居中控台：对屋子说一句中文，它先解析成结构化的设备指令，再一台一台地执行，画面和用电实时跟着变。没配大模型也能用，配了就走 LLM 解析，失败自动降级。

## 3 分钟演示路线

1. **先说结论**（15 秒）：这是「自然语言 → 结构化指令 → 设备动作」的完整闭环，不是聊天玩具。
2. **输入 `我回家了`**（40 秒）：让面试官看右边「01 / 解析」——一句话被拆成 5 条指令，每条都有 `device / on / level / target`，下面是原始 JSON。
3. **指出画面**（20 秒）：屋子先拉窗帘、再开灯、空调出风，是**按顺序**动的，不是一次性刷新。
4. **输入 `把主灯调到 60%`**（20 秒）：证明它不只会识别场景，还能抽取数字参数。
5. **点一下页面上的「有点冷」**（20 秒）：体感兜底，空调温度自动上调。
6. **打开设备面板手动拖滑杆**（15 秒）：手动控制也走同一套状态机，SSE 把状态推回页面。
7. **翻到「04 / 指令历史」**（15 秒）：每条指令都落库了（SQLite），刷新页面还在。
8. **收尾**（15 秒）：强调「双引擎 + 降级」这个设计决定。

## 被追问时怎么答

**Q：为什么不用大模型直接返回一句话，非要拆成 JSON？**
因为要执行。一句话没法驱动设备，也没法单测。拆成 `Action[]` 之后，本地引擎、大模型、手动面板三条入口产出同一种类型，上层完全不用改。这是整个项目的核心边界。

**Q：没有 API Key 也能用，是不是说明 AI 是假的？**
本地引擎是规则解析，不是 AI；但它保证了 demo 永远可跑。配了 Key 之后走的是大模型解析，页面上的徽章会变成「大模型解析」。两条路径的结果类型一致，可以随时对比。

**Q：大模型返回的 JSON 不合法怎么办？**
三层防护：`response_format: json_object` 约束输出格式；zod 校验设备 id、参数范围、动作条数；任何一层失败都返回 `null`，`/api/command` 立刻降级到本地规则。用户只会看到「这次用本地规则解析」，功能不残。

**Q：状态为什么放在内存里？**
单实例演示够用，而且屋子状态本来就是易失的实时数据。真要上多实例，把 `lib/house.ts` 里的 runtime 换成 Redis，广播换成 pub/sub，其余代码不用动——这正好说明状态机是独立的一层。

**Q：SSE 和 WebSocket 为什么选 SSE？**
只需要服务端单向推状态，SSE 是原生 `EventSource`、零依赖、自动重连，比 WebSocket 简单。指令下发走普通 POST，不需要双向通道。

**Q：功率和用电是编的吧？**
是模型算的，但每个数字都能对上：主灯 24W 按亮度比例、风扇 45W 按档位、空调 760W + 每低 1 度加 45W。`lib/house.ts` 里 `wattsOf` 是纯函数，测试里逐条验证过。

**Q：这个项目最难的地方？**
不是接模型，是「让人话和机器状态对上」：别名（落地灯 vs 灯）、场景的多动作、参数抽取（60%、26 度、三档）、以及「听不懂时也不能乱动设备」。这些都在 `lib/intent.ts`，也是单测覆盖最多的地方。

## 代码地图（被问「这块怎么实现的」时打开对应文件）

| 想讲什么 | 打开 |
| --- | --- |
| 一句话怎么变成指令 | `lib/intent.ts` 的 `parseIntent` |
| 大模型怎么接、怎么降级 | `lib/llm.ts` + `app/api/command/route.ts` |
| 设备怎么按顺序动 | `lib/house.ts` 的 `applyActions`（每条广播一次） |
| 实时状态怎么推 | `app/api/events/route.ts`（SSE + 1s ticker） |
| 功率怎么算 | `lib/house.ts` 的 `wattsOf` / `totalWatts` |
| 屋子怎么画的 | `components/RoomView.tsx`（纯 SVG，无第三方图表库） |
| 数据怎么存的 | `lib/db.ts`（`node:sqlite`，零依赖） |

## 还可以继续做（被问「下一步」时用）

- 加一个「模糊指令 + 追问」：`把灯调暗一点` 时先问「哪盏灯？」
- 设备分组与房间：`light.ceiling` 的 id 已经预留了「类型.位置」，可以直接扩成多房间
- 把本地引擎替换成一个小的意图分类模型，和 LLM 做 A/B 对比
- 用真实硬件协议（MQTT / Home Assistant）替换模拟执行层
